# Вектор роста

Информационная страница медиапроекта о предприятиях России, людях и карьерных возможностях в промышленности.

Статический сайт без сборки. Основные файлы: `index.html`, `style.css`, `assets/`.

## Публикация

В настройках репозитория откройте Settings → Pages. Выберите Deploy from a branch, ветку `main` и папку `/ (root)`, затем сохраните. Адрес опубликованного сайта появится в разделе Pages.

## Локальный просмотр

Откройте `index.html` в браузере или выполните `python -m http.server 4173` из каталога сайта.
